# External asset route research

**Audit date:** 2026-09-23  
**Scope:** first-party Hugging Face, GitHub, PyPI, and the official CALVIN
download server only. No local/private asset directory was inspected, and no
large asset was downloaded. A route is marked **unresolved** when an immutable
revision, file digest, or license could not be established from a first-party
source. A URL that happens to be reachable is not treated as a reproducibility
pin by itself.

## Executive result

The software dependencies have identifiable public sources, but the three
paper-level benchmark inputs do not form a complete immutable release:

- **ManiSkill:** the runner baseline is ManiSkill `v3.0.0b22` at commit
  `33967b9e3ead1f841eec57cc9f31d0d8b8cf0907`, as selected by the pinned RLinf
  installer. The newer `v3.0.1` tag is retained below only as a research
  reference for upstream asset metadata; it is not the runner baseline. The
  upstream source lists several checksummed asset downloads. RLinf also
  publishes a task-asset dataset route. Official Hugging Face download-cache
  metadata also records immutable revisions and model-file hashes for the
  π0.5 SFT and FlowSDE teacher pages. Those cache records are useful download
  evidence, but live Hub/API and card revalidation remains pending; the model
  license and complete task-asset closure are not established. No Path-OPD
  paper checkpoint or formal evaluation panel was found in the official
  sources checked.
- **CALVIN ABC→D:** the official server publishes the 517 GB
  `task_ABC_D.zip` archive and a SHA-256 manifest. The simulator and evaluator
  are public Git repositories. The official evaluator generates a 1,000
  sequence, five-subtask panel from code and a fixed seed; there is no separate
  panel file in the repository. The old MCIL baseline checkpoint has a public
  URL but no matching SHA-256 entry. A Path-OPD paper checkpoint and a complete
  immutable annotation/panel bundle remain unresolved.
- **MetaWorld MT50:** package tag `3.0.0` is pinned to a Git commit and has an
  MIT license. The official evaluator defines 50 episodes per training goal
  for each of the 50 tasks, but the goal states are generated by the
  environment rather than shipped as a content-addressed panel. Official
  Hugging Face download-cache metadata records immutable revisions and
  model-file hashes for the π0.5 SFT and FlowSDE teacher pages; live Hub/API
  and card revalidation remains pending, as do the model licenses. No
  Path-OPD paper checkpoint or immutable formal panel was found.

This means the release may document external download instructions, but must
continue to fail closed and must not claim independent reproduction of the
paper tables until the unresolved fields are supplied and recorded.

## Endpoint and license notes

The GitHub and PyPI checks used official JSON/raw endpoints. The official
Hugging Face model and dataset page URLs were confirmed as the canonical
routes used by RLinf documentation. Repeated requests to the Hub API and
tree endpoints returned connection resets from this environment, so the
ManiSkill and MetaWorld revisions/hashes above come from official download-
cache metadata rather than a live API response. Once network access is
available, each cache record must be revalidated against the Hub commit,
exact `resolve/<sha>/<file>` URL, file SHA-256, card license, and any
gated-access condition.

For the same reason, the `RLinf/maniskill_assets` dataset route is documented
as a public candidate, not as proof that every required ManiSkill asset is
licensed or complete. The existing [external source index](EXTERNAL_ASSET_SOURCES.md)
contains earlier observations; this note records the independent boundary of
what was and was not revalidated on the audit date.

## Release decision

The repository may ship links and caller-supplied asset contracts for review,
but it should continue to state **NOT_QUALIFIED** for paper-level reproduction
until all three benchmarks have a qualified external runtime run, a pinned base
and teacher model, a hashable result checkpoint, and an explicitly recorded
formal evaluation panel.
